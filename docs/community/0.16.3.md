# LibreEcho 0.16.3 source and hardware results

This independent, AI-assisted LibreEcho fork prepares native Sendspin and local phone intercom for the **full-size Amazon Echo 2nd Generation (2017), Radar/Puffin**. LibreEcho was created by Andy Slater and its contributors. See [attribution](../../ATTRIBUTION.md), the [AI disclosure](../../AI_DISCLOSURE.md) and the [full disclaimer](../../DISCLAIMER.md). The fork offers no repair, recovery, unbricking or replacement service.

## What was tested

- **0.16.3 on one Echo 2.** Signed OTA installed and confirmed, Home Assistant reconnected, and the owner confirmed audio in both directions during one foreground iPhone Safari intercom call. The speaker audio connection closed when the call ended.
- **Earlier native Sendspin testing.** The owner verified audible Music Assistant playback and voice controls on 0.15.1, and judged two-speaker playback aligned after restarting the group. 0.16.3 includes the Sendspin recovery changes. Long-duration and instrumented sync remain unverified.
- **Local tests for 0.16.3.** The intercom suite passed, including recovery after a temporary speaker audio stall and cleanup if the stall persists. The built image, signature, installer preparation and feature assets passed local checks. The first 0.16.3 hardware test used OTA. A fresh install of this version remains to be verified on a second device.

## Setting up a supported speaker

Enable Sendspin under **Integrations** and pair the speaker in Music Assistant using its own token. For intercom, select Home Assistant voice mode, use trusted HTTPS for the speaker's address, enable room calls explicitly and allow microphone access in foreground Safari. Set up a separate owner account, certificate and pairing for each speaker.

See the [Sendspin guide](https://github.com/sn45k58myn-dev/LibreEcho/blob/595daa2a723f84204cd9cd6d5256ab0eab0ea10c/docs/audio/sendspin.md) and [intercom guide](https://github.com/sn45k58myn-dev/LibreEcho/blob/595daa2a723f84204cd9cd6d5256ab0eab0ea10c/docs/audio/intercom.md). The hardware test above supersedes the intercom guide's original pre-test status.
