# Echo 2 0.16.8 · iPhone intercom echo cancellation

On the full-size Amazon Echo (2nd Generation, 2017; Radar/Puffin), a caller could hear their own voice returning through the iPhone after speaking. This release filters the audio sent from the room microphone back to the caller during an active intercom call. It includes native Sendspin and the earlier microphone and call-audio fixes.

## Use 0.16.8 on the next Echo 2

A new owner can [build the complete 0.16.8 kit from public sources](BUILD_ECHO2_0.16.8.md) on Linux. That route creates a signing identity for future updates and requires no previous firmware archive.

1. Confirm the unit is a full-size Echo 2 with the `radar_puffin` target and meets the installer's first-install requirements. The Echo Dot 2 and Echo Studio have different hardware.
2. For a **first installation**, keep the complete 0.16.8 kit together. For a source build, the output directory contains its `*-installer.py`, `*-initial-install.tar`, five matching feature packages, manifests and `*-SHA256SUMS`. Use that directory as the installer's local release directory. For the original retained kit, its start guide identifies the firmware directory and matching host installer. The intercom fix comes with the wakeword feature. A prepared speaker can start directly at 0.16.8. A fresh install on a second physical unit is pending.
3. For **an existing LibreEcho installation**, use the signed 0.16.8 OTA and its matching feature set with the installed signing trust. The update was confirmed on one Echo 2. Each route requires the installer's normal model, signature and feature checks.
4. After boot, check that the device reports **0.16.8** and that the voice feature is ready. Pair its own [Sendspin player](../audio/sendspin.md) with Music Assistant. Select Home Assistant voice mode, complete trusted HTTPS setup for this speaker, then explicitly enable **Allow calls to this speaker**. [Phone intercom setup](../audio/intercom.md)
5. From another room, place a call in foreground Safari. Have someone speak at each end, then listen during a pause for any return of your own words. End the call and check that the speaker responds to its wake word again.

## What was verified

- **On-device diagnostic before the final update.** On one Echo 2 running the temporary measurement build, comparing the same microphone frames with the original and revised processing, the two usable test tones showed about 7 dB and 14 dB less returned sound. A third tone did not qualify. These numbers describe echo level. Overall conversation latency was not measured in that comparison.
- **Signed 0.16.8 on hardware.** The Echo confirmed startup on the updated slot, reconnected to Home Assistant and exposed its intercom and Sendspin listeners. The installed audio executables matched the signed build. An iPhone caller reported that the echo sounded much better during a normal call. Instrumented multi-speaker sync on this release is still untested.
- **Offline checks.** The installer accepted the complete first-install bundle and all five signed feature bindings. The final call filter matched its reference across 26 test cases and 314,400 audio samples. The daemon tests covered call permission, mute and privacy, hang-up and subsequent calls.
