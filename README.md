# Echo 2 0.16.8

This is the community build for the full-size **Amazon Echo (2nd Generation, 2017), Radar/Puffin**. It reduces the caller's voice coming back through the iPhone during a two-way intercom call and includes native Sendspin.

The signed OTA started successfully on one Echo 2, reconnected to Home Assistant and restored its Sendspin listener. An iPhone caller reported less echo during a normal call. In the preceding six-second speaker diagnostic, the two usable tones showed about 7 dB and 14 dB less returned sound.

**For another prepared Echo 2**, use the complete 0.16.8 first-install bundle and the five matching feature packages directly. No older LibreEcho install is required. Offline preparation and signature verification passed. A fresh install on a second physical unit is pending. The first-install tar and OTA contain third-party components and are retained locally. [Installation, tests and exact sources](https://github.com/sn45k58myn-dev/LibreEcho/blob/docs/community-publication/docs/community/0.16.8.md)

The source-changes ZIP contains the UI and Platform patches from the previous public 0.16.3 source, along with the licences. Both reproduce the tested Git trees. The JSON records all four exact source pins. The firmware checksum file checks the completed kit.

Based on LibreEcho by Andy Slater and its contributors. This independent fork includes AI-assisted additions.
